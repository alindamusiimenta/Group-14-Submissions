# Individual Week 3 Reports

There is one report for each member: `member-01.md` through `member-10.md`. Each member continues the same area they owned in Week 2. Replace the placeholders with real names, student numbers, branch names, pull-request links, commit hashes, and exact references.

Each report should clearly answer:

1. What did I own in Week 2?
2. What did I add in Week 3?
3. What does the new code receive and return?
4. How does it connect to the LASSO pipeline?
5. How did I test it?
6. What will I do before final submission?

A member should explain the idea in their own words. For example, the scaling report should explain why statistics are learned from training data only and reused on test data. The coordinate-descent report should explain what one pass and the stopping tolerance mean.
